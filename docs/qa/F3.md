## Known gap: materials/certification-gating isn't click-through-testable today
Every program in `seed.sql` is deliberately kept unlicensed (CLAUDE.md invariant #10 - "Ivan updates these once terms are real"), and `enforce_cohort_program_and_facilitator` blocks assigning a facilitator+program cohort unless the program is licensed. That makes it impossible to seed a real cohort with both a `program_id` and materials attached without flipping a program's license status outright, which this PR does not do. The materials/certification-gating half of F3 (an uncertified facilitator blocked from materials, with a reason) is instead verified by:
